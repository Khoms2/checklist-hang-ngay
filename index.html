📖 Hướng dẫn tạo Firebase (miễn phí)
  1. Vào Firebase Console
  2. Bấm "Create a project" → đặt tên → tạo
  3. Vào Build → Realtime Database → Create Database → Start in test mode
  4. Vào Build → Authentication → Get started
  5. Bật Google và/hoặc Email/Password provider
  6. Vào Project Settings (⚙️) → cuộn xuống "Your apps"
  7. Bấm </> (Web) → đặt tên → Register
  8. Copy phần firebaseConfig = {...} → paste vào ô trên
